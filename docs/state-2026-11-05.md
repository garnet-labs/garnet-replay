# Harness state, 2026-11-05

The state of the harness after the PostHog fork retro (garnet-labs/posthog #246 and #249). A cold operator should be able to follow this file alone.

## What works

- **Consumption.** `card`, `decide`, `consume` and `rows` read the finalized App comment bound to the PR head (`garnet:commit` = head). They take the result from the `garnet:summary` marker and the job folds, never from the prose. They report the App result as the App states it:
  - `changed` stays changed.
  - `nothing new` stays the App's scoped result and is never relabelled unchanged or complete.
  - A removed job is listed but is not a change by itself.
  - Scope `pr-base` is the App's last recorded runs on the base branch.
- **Strict share gate.** `replay verify` is unchanged. On current records it fails `capture completeness` (best-effort) and `public profile identity`, because profiles bind to `refs/pull/N/merge`, not the head. So every current row is a scoped result, not shareable as complete.
- **Cohort rows.** `replay rows <manifest.json>` reads each fork PR through the GitHub API and writes `rows.json`, `table.md` and a research-note skeleton (`note.md`). It reads:
  - the App comment;
  - the fork's `Dependency proof` check;
  - StampHog's sticky comment (verdict, reviewed head, attested and unattested files);
  - optionally the upstream PR (approver, hours open to merge, revert search) and strict verify.
  - Counts in the note come from the rows only. The operator fills a real-vs-infra class per new host in the manifest.
- **Label after record.** A replay with `--label` waits for the head's finalized record before it applies the label. If the record is not final, the label is skipped and the log says so. A reviewer labelled earlier reads no record.
- **Hosted job.** The `replay` workflow's `base_branch` input reaches `bin/replay-job.mjs` as `REPLAY_BASE_BRANCH` and `live` as `--base-branch` (a plain branch name, never the default branch).

## What is still scoped, manual, or open

- Every current record is `capture_quality: best-effort`. Cards say "scoped result, not complete capture", and `decide` exits 2 (`undeterminable`).
- Runner and registry noise (setup-uv, apt mirrors, `pypi.org` vs `files.pythonhosted.org`) still lands in `changed`. That is a control-plane classifier item. The harness adds no allowlist; the operator classifies each host in the manifest.
- Replay authoring:
  - `live`, `setup` and `refresh` still need a local `--work` checkout, which the untrusted-repos rule forbids for third-party forks. Use the hosted `replay` workflow (GitHub-hosted runner).
  - Applying an upstream diff as a text patch onto fork-base files (instead of a cherry-pick or upstream blobs) is not built yet. Until it is, mark chained or hand-shaped rows `chained: true`.
- Reviewer kit drift: `verify` reports `reviewer grounding` missing or conflicting on garnet-labs/posthog. Run `replay ground posthog --dry-run` and merge its onboarding PR; never hand-edit.

## Operator commands (Node 20+, tested on v24.22.2)

Node must be on `PATH` (with nvm: `nvm use 24` or `export PATH=$HOME/.nvm/versions/node/v24.22.2/bin:$PATH`); there are no npm dependencies and no git hooks to install. Env (names only): `GH_TOKEN`. Use a token that can read garnet-labs. Without it, the GitHub REST calls in `decide` and `verify` hit the anonymous rate limit (403). `gh` must be authenticated, and `gh api` must run from a checkout of a Garnet-owned repository.

```sh
cd ~/repos && git clone https://github.com/garnet-labs/garnet-replay && cd garnet-replay   # gh api runs from here
npm test                      # expect: all pass, 0 fail
export GH_TOKEN=$(gh auth token)   # never echo it
P=https://github.com/garnet-labs/posthog/pull
node bin/replay.mjs verify $P/246; node bin/replay.mjs verify $P/249
node bin/replay.mjs card $P/246;   node bin/replay.mjs card $P/249
node bin/replay.mjs decide $P/246; node bin/replay.mjs decide $P/249
node bin/replay.mjs consume $P/246; node bin/replay.mjs consume $P/249
printf '%s\n' '[{"fork":"'$P'/246","authorClass":"bot"},{"fork":"'$P'/249","authorClass":"bot"}]' > /tmp/rows.json
node bin/replay.mjs rows /tmp/rows.json --out out/rows
```

`card` and `decide` update `targets/posthog.json` (ledger rows). Discard that diff with `git checkout -- targets/posthog.json` unless you mean to keep it.
